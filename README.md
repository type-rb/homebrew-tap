# homebrew-tap
Homebrew tap for TypeRB

Install the compiler with `brew install type-rb/tap/trb`.

Install the Go implementation alongside it with `brew install type-rb/tap/trbg`.
Use `trbg` for Go, Ruby, and TypeScript source builds. In the TypeRB extension for
Visual Studio Code, set `typerb.server.path` to `trbg` to use the Go
implementation in a workspace.
